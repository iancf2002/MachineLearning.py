# Regressão Linear Simples com Scikit-Learn

Este projeto implementa um modelo de **Regressão Linear Simples** em Python para analisar a relação entre o tempo dedicado aos estudos e o desempenho acadêmico (notas). 

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* **NumPy**: Para manipulação e estruturação dos dados de entrada.
* **Scikit-Learn (sklearn)**: Para criação, treinamento e predição com o modelo estatístico.
* **Matplotlib**: Para visualização gráfica dos dados reais e da reta de regressão.

## 🚀 O que o código faz?
1. **Treina um modelo** utilizando um conjunto de dados de horas de estudo ($X$) e notas obtidas ($y$).
2. **Calcula a equação da reta** ($y = ax + b$) que melhor descreve a tendência dos dados.
3. **Faz uma previsão** de resultado com base em um novo valor de entrada.
4. **Gera um gráfico descritivo** exibindo os pontos reais e a linha de tendência linear gerada pela inteligência artificial.
